## 三、这一天修掉的**既有** bug（不是我引入的，但今天才看见）

### 1. 判断题在题册页显示成 `truefalse`

`BookPage.tsx` 与 `BookSelfTest.tsx` 各有一份手写的 `kindLabel` switch，
**都缺 `truefalse` 分支** → 落进 `default` 返回原始值。

**这已经暴露了「三处手写同一张映射表」的结构问题**：
`cards.ts` 里还有第三份 `CARD_KIND_LABEL`。三处各自维护，加题型漏一次就露英文。

**已全部改成从 `kinds.ts` 的 `kindSpec()` 取**（单一数据源）。

### 2. `toCardKind` 的 `default: return 'single'` 是陷阱

未知题型会静默退回「单选题」，做题界面于是渲染出
「没有选项可点、也没有输入框」的死按钮。

**这个 default 本身没写错**（防止崩），但它是**静默**的 ——
加新题型时漏改这里，tsc 不会报、单测也不会报。

**建议**：以后加题型，第一件事是在 `toCardKind` 里显式加 case，
然后去真实界面做一道题。

### 3. 残留的 `converted.md` 会让解析失败被误判成成功

`runMineru` 的判定是「输出文件里有内容就算成功（不看退出码）」——
这是有意的（MinerU 有时报错但退出码 0）。

但 `outDir` 里若留着**上一次**的 `converted.md`，这次完全失败也会读到旧内容、
误判成成功。**已修：开跑前先删旧输出。**

## 五、关键设计（新增，供下一任理解）

### 5.1 变式出题：素材即约束

`QuestionBackend.generate()` 只认 `QuestionSourcePoint[]`。
变式只做一件事：把「一道旧题 / 一个知识点」翻译成一条素材。

**代价**：变式约束（换情境 / 反向问 / 合并 / 加深）必须写在素材文本里。
所以 `variants.ts` 里那三条硬性限制很关键：

1. 只在「原题 + 原文引用」共同支撑的范围内变化
2. 考点必须与原题一致
3. 不要出现「原题」「上题」（学生复习时看不到原题）

### 5.2 MinerU 的几处「必须分开传」

| 命令 | 要不要 `MINERU_HOME` | 为什么 |
|---|---|---|
| `mineru-kit models show` | **必须带** | 不带会去查 `~/.mineru`（另一个目录），结论错 |
| `mineru config get/set` | **不能带** | 带了会去找那个 home 的 doclib 配置，缺 token 时直接失败 |

两者要求相反，`mineru-health.cjs` 里分别传。

### 5.3 `server` 是全局单例

`mineru server status` **不看 `MINERU_HOME`**，只看 `%USERPROFILE%\.mineru`。
所以 A 方案（已有就不装第二份）是对的：装第二份会和已有那份抢服务，
两份 `doclib.auth.token` 不同 → parse 报 `invalid_doclib_token`。

## 八、教训（写给下一个接手的人）

1. **「把卸载器复制到别处跑」不是隔离。** NSIS 的 `$INSTDIR` 编译时写死。
   我今天因此删了用户的安装与学习库。

2. **功能做出来 ≠ 用户能用上。** 这一天的三次「用户问了才发现没接上」
   （变式入口 / 一键安装被隐藏 / 计算题没有输入框）都是这个。

3. **`default: return 'single'` 这类静默兜底要特别小心。**
   它防崩溃是对的，但会让「漏改」变得无声无息。

4. **同一张映射表不要手写三份。** 题型标签今天暴露了三处，
   漏一处就露英文。现在已统一到 `kinds.ts` 的 `kindSpec()`。

5. **验证脚本自己也会错。** 今天多次踩到：
   - e2e 在异步完成前读库 → 修复前后都「通过」（假通过）
   - `getAll()` 按主键序返回，界面按 `order` 排序 → 「改的是 A、查的是 B」
   - 在整页 `button` 里用 `indexOf` 找侧栏项 → 匹配到页面内按钮
   **反向验证**（用修复前的代码跑）是唯一能证明脚本真能抓 bug 的办法。

6. **用户的话要读准。** 计算题判分方案我理解错了一次，
   用户不得不解释第三遍。**他不确定的方案，动手前先问。**

7. **诚实报告边界。** 今天有几件事我没能确认到底（13 个快捷方式是谁删的、
   CS 那 58GB 去哪了），我如实写了「不知道」，没有编一个解释。
