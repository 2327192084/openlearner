## 二、⚠️ 本轮（11-23）最重要的一节：我自己引入的回归

### 现象

闪卡 callout 第一版：头部「两个周期信号之和的周期性取决于…（截断）」，
正文「两个周期信号之和的周期性取决于…（完整）」—— **同一句话显示两遍**。

用户库 8 张知识点卡正面**全是单行长句**（实测 66 字一行），所以**每张卡都中招**。

### 为什么 33 条单测全绿没抓到

单测只验纯函数（`cardTitleOf` 截断对不对、`splitRichLines` 角色对不对），
**没有任何一条验"头部与正文是否重叠"**。

是**看截图**发现的 —— 这条约束（最高优先级）本轮再次被印证：
断言全绿 ≠ 界面对。

### 修法

新增 `splitFrontTitle`：**只有正面确实多行时，第一行才算标题**，
且正文只渲染剩余行。单行正面 → 头部没有标题（连「｜」都不出）。

Obsidian 的 `[!tip]` 不写标题本来就合法，所以"没有标题"不是降级。

### 反向验证（两组都做）

- 改回「永远取第一行当标题」→ 1 条单测红
- 同样改坏 → `verify-card-callout.cjs` 的反重复断言也红

### 同类错误在项目里出现过几次

| 时间 | 表现 | 共同点 |
|---|---|---|
| 11-13 | 阅读器 chapter 与正文第一行重复两次 | 同一信息渲染两遍 |
| 11-22 深夜 | 有路线但没地图（只重写数据层忘渲染层） | 断言全绿 |
| 11-22 中午 | 三个章各显示 0/26、总数 0/78 | 断言没查总数 |
| **11-23** | **callout 头部重述正文** | **断言没查重叠** |

**规律：断言的盲区总在"两个部分之间的关系"上**（重叠、重复计数、
一致性）。单点断言再密也抓不到。下一轮写断言时先问：
「头部和正文会不会说同一件事？」

## 四、markdown 与数学的边界（我推翻自己两次）

1. **原以为「先整行渲染数学、再对 HTML 做 markdown」可行**
   用 KaTeX 实测否掉：LaTeX 里的 `*` 会被转成 `∗`（U+2217），
   渲染结果里**没有 ASCII 星号** —— 所以坏实现也"碰巧"不加粗。
   最终改成 `splitMath` 切段，markdown 只作用于非公式段。

2. **第一版测试用一对星号 `$a ** b$`**，反向验证时坏实现照样全绿
   —— 加粗规则需要**两对**才匹配。那就是「断言写得够宽 = 没在验」。

⚠️ 现在测试注释里**如实写明**：那条断言拦不住坏实现，
保留理由是钉住设计约定（以后有人改 `render-math` 时它会变成真防线）。
**教训：反向验证没变红，先怀疑断言，别怀疑实现。**

不认 `_斜体_`：数学下标 `x_1` 极常见，认了会吃掉公式。

## 八、本轮踩的坑（新增，都写进了代码注释）

1. **shell heredoc 吃转义**（我这次会话连踩三次）
   `python - << EOF` 里的 `\n`、`\s` 会被吃掉，产出
   `split('` + 真换行 + `')` 这种语法错误。
   **正解：改代码用 `edit` 工具**（字面量直接传，不经 shell）。
   硬约束 10 说的是"含反引号/反斜杠/中文"，我以为是"写文档"，
   其实**改代码同样适用**。

2. **`python3` 在 Windows 是 Store 假壳**
   命令静默不执行（无输出、无报错）。要用 `python`。
   `which python3` 会指到 `WindowsApps/python3`，别看它存在就用。

3. **读取工具会转义显示**
   `ops_read_files` 把文件里的 `\s` 显示成 `\\s`，
   所以拿它输出的内容当 `edit` 的 `old_string` 会不匹配。
   锚点要按**真实字节**（单反斜杠）写，或改用行号定位。

4. **函数搬家要先查谁在用**
   `shortTitle` 原本住在 `RouteBoard.tsx`，而 `RouteTree` 一直在借它。
   直接删死代码会把树弄坏。先 `grep` 依赖再删。

5. **删死代码会带走活功能**（两次）
   - `mapFocus` 删了 → 首页「题组进度」行点了没反应
   - `treeStatsError` 的显示方（MapPage）删了 → 错误只 set 不显示
   `tsc` 抓不到这类（值还在被 set，只是没人读）。
   **删之前要问：这个变量在界面上负责什么？**
