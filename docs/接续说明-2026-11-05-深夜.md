### 打包（重要，踩过两次坑）

```bash

cp electron/*.cjs .pack-tmp/app/electron/

cp .pack-tmp/app.asar release/win-unpacked/resources/app.asar
```

  `TMPDIR=E:\openleaner\.tmp-esbuild` 再跑。

  **必须用 `OpenLeaner-Launcher.bat` 启动**（直接跑 exe 会因 Chromium 沙箱崩溃、无任何提示）。

### 验收脚本注意事项（踩过四次）

1. **CDP `eval` 走模板字符串，`\s` 会被吃掉**。要传正则给浏览器，源文件里必须写**四个反斜杠**。
2. **Edge 残留会锁住 profile 目录**（EPERM）。跑前先杀：
   `Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" | Where CommandLine -like '*--headless=new*'`
3. **长脚本跑完不退出**（CDP 的 WS + 120s 定时器挂住事件循环）。已有脚本在 `finish()` 里强制退出。
4. 断言别搜整个 `body` —— 打包进来的 JSZip 含 `ZIP64` 常量，字面含 "P6"，会误判成文案。

### 几条重要的设计决定（别推翻）

- **角标链路**：要点 → `citationIndex` → `SlideCitation` → `segmentId` → 段落页码。
  模型**只指回段落 id，绝不给页码**。这是「每条内容都能点回原文」的落点。
- **PPT 从资料原文生成**，不是从知识点二次加工。可按页码范围取材。
- **主题单一来源** `src/core/slides/theme.ts`，预览与导出都走 `resolveDeckTheme()`。
  两处各写一套会导致「预览深蓝、导出黑色」。
- **叠加内容坐标存 0~1 比例**，不是像素。存像素换屏幕就错位。
- **图片上限 8MB**，拦在 `addImage` 写入口而不是界面（界面有多个入口，漏一个就绕过）。
- **假开关一律摘掉**：已摘「联网检索」勾选框、`agent-app` 类型、本地 OCR 死标签。

二进制随包内置（77MB）、应用内授权窗口。

**卡住的三个障碍**：

1. **Electron 在无图形会话里段错误**（`exit=0xC0000005`，`app.whenReady()` 从不触发）

2. **UAC 权限隔离**：用户的 OpenLeaner 以**管理员权限**运行，Windows 不允许高权限进程
   把 URL 交给低权限的系统浏览器，点登录链接会弹
   「Microsoft Edge 未响应，因为现有实例正在以提升的权限运行」。
   → 修法是应用内窗口（`openAuthWindow`），但那一步没验证成。
3. 网络：GitHub 下载需代理。已加自动探测（环境变量 → 7897/7890/10809 等）。

**建议下次拆小步**：先只做 `1b51a30` 那个提交（本地代理预设 + 模型发现），
不含 sidecar、不碰子进程和窗口，可以完整验证。

## 六、容易踩的坑（都真踩过）

| 现象 | 真因 |
|---|---|
| `vite build` 报 `Access is denied` | esbuild 临时文件被锁，设 `TMPDIR` 到工作区 |
| `electron-builder` 超时/ECONNRESET | 联网下载依赖失败，改离线手工组装 |
| 验收脚本 `EPERM` 删 profile | 上次的 headless Edge 没退，先杀进程 |
| 验收脚本卡 10 分钟 | CDP 的 WS/定时器挂住事件循环，`finish()` 里强制 `process.exit` |
| 正则断言永远失败 | CDP 模板字符串吃掉了 `\s`，源文件要写四个反斜杠 |
| 桌面版双击无反应 | Chromium 沙箱崩溃，必须走 `.bat` 启动器 |
| 预览与导出配色不一致 | 主题写了两份；现在统一走 `resolveDeckTheme` |
