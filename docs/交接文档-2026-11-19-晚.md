### 2.1 从 LogiNote 借到手的三条

**① 答错 → 针对性补充讲解**（`a60d638`）

答错后界面上原来只有整题 `explanation`（出题时写死的）与逐选项 `why`。
用户卡住的常是更具体的地方：「我选 B 是因为我以为条件对称 —— 到底哪步想错了？」。

- 5 种讲法（直接讲/举例子/讲故事/分步骤/对比着讲）+ 自定义要求
- 提示词把**分岔点**喂给模型：选错的选项 + 那个选项的 why + 正确答案
- 落库用可选字段 `Question.explainNotes?`（零迁移，追加不覆盖）
- 按讲法分类显示，默认只看最新一条；整块可收起

**② 提示阶梯**（`3d9d743`）

做题只有「会 / 不会」两态，卡住时唯一出路是直接看答案。

- 四级：方向 → 拆小问题 → 关键条件 → 相似例
- **最要紧的一条**：用了 3–4 级强提示才答对的题**不算真会**
  （`judgeMasteryWithHints`；`ReviewLog.hintLevel?` 记下来）
  否则提示会变成安慰剂，让间隔调度系统性误判

**③ 逐选项解析 why**（`d3d072c` ①）

提示词第 6 条一直在要求「每个选项都要写为什么」，`QuestionOption.why` 有长注释、
`cards-loader` 透传、`ReviewPage` 会渲染 —— 但 `QuestionDraft.options` 的类型里
没有 `why`，解析时被静默丢掉。**我们一直在付 token 让它写，然后扔掉。**

### 2.2 不是从 LogiNote 来的（顺手修的）

- **189 处失效 CSS 变量**（`d70d0b4`）：`--text-1/2/3`、`--surface-*`、`--font-sm`、
  `--radius-2`、`--line-subtle`、`--c-warn` 等**从来没定义过**，全部静默回落到硬编码的
  深色主题值。`scripts/check-css-vars.cjs` 早就扫到了，但把「有 fallback」判成
  「不坏，可能是拼错」而**放行**（退出码 0）—— 于是一直没人管。现已改成硬失败。
- **笔记归属 bug**（`f04b840`）：做题时写的笔记，到学习笔记页只显示资料名，
  点进去跳原文而不是那道题。根因是 `groupTitle` 在「有资料」时一定是资料名，
  拿它当「归属」显示必然丢题目信息。
- **答疑记录整合**（`d4ba865`）：把「提问式复习」与「错题讲解」合成一处
  （原来讲解那份**根本没有入口**）。只在展示层合并，两份数据原样保留。

## 三、关键设计（别推翻，理由都在这）

### 3.1 两个讲解面板位置相反，用的 token 也就相反 —— 这个坑踩了两次

| 面板 | 位置 | 该用什么颜色 |
|---|---|---|
| 答错补充讲解（`ExplainPanel`） | 纸张卡**里面**（`.question-card.paper`） | `--paper-ink` / `--paper-dim` |
| 提示阶梯（`HintPanel`） | 纸张卡**外面**（深色画布） | `--text*` / `--line-*` |

第一次做 `ExplainPanel` 时用了 `--text-*`（深色主题），在纸卡里挖出一块深色；
第二次做 `HintPanel` 时反过来用了 `--paper-*`，深色字压在深色画布上，
**截图一看几乎完全看不见**（断言 10/10 全绿时没暴露）。

两个 CSS 文件的头注释都写清了这件事。

### 3.2 按钮颜色必须写在层外，而且不能靠 `:where()` 压权重

`src/styles/base.css` 有一条**不在任何 `@layer` 里**的
`button, input, select, textarea { color: inherit }`。
层外规则优先于层内 —— **这比 specificity 还优先**，所以 `@layer` 里给按钮写的
`color` 一律无效。

我第一版修主按钮时写成 `:where(.btn-fill)`，想压低权重更安全。
**没生效**：`:where()` 的 specificity 是 0，而 `button` 是 (0,0,1)，
层外规则之间照样比 specificity，又输了一次。最后用 `.app .btn-fill`（0,2,0）。

这个错误是 CDP 读 `computedColor` 抓到的，不是靠读代码看出来的。

### 3.3 `useCallback` 依赖数组漏字段 → 闭包捕获旧值

提示阶梯要做「用了第几级提示→不算真会」，但 `submitGrade` 的依赖数组里
没有 `maxHintLevel`，于是闭包永远读到初始值 0，**用了 3 级提示写成库里是空的**。

界面全绿 —— 是端到端读 `reviewLogs` 才发现的。

### 3.4 一份真相：不要「乐观展示 + 落库结果」两份状态

`ExplainPanel` 第一版同时渲染 `notes`（从库读的）和 `fresh`（刚生成的乐观展示）。
但 `fresh` 那条**同时已经落库**，下一帧 `notes` 里也有它 —— 同一条渲染两遍
（用户截图报的正是这个，第 2、3 条内容一字不差）。

现在只渲染 `notes`（唯一真源），落库后从库里读回真实记录刷新缓存。
代价是等一次存储往返（几十毫秒），换来「只有一份真相」。

### 3.5 「没考查到」不等于「做错了」

三层证据打分第一版是固定权重 `concept*0.4 + judgment*0.3 + reasoning*0.3`。
测试立刻抓到：概念层满分、推理层因**没问到**而全 false 时，overall 只有 0.4 ——
低于 `correct` 的 0.6 线，等于「把定义答对了却被判成记忆错误」。

改成**按实际考查到的层重新归一化**（只答概念时概念层就是全部）。
这与 LogiNote 的证据边界「未考查到的能力记为未观察到，false 不等于答错」
是同一条原则的数学落地。

### 3.6 答疑记录只在展示层合并，不动数据

两类记录字段差别很大：提问有「记错/理解偏」判定与引文，讲解有讲法与你选了什么。
强行合并成一张表要么丢字段，要么要迁移用户已有的真实记录。

`v2/core/answer-record.ts` 做归一（纯函数，18 条单测），
`oralReviews` 与 `questions.explainNotes` 保持原样。

### 3.7 命名：答疑记录

「提问式复习」与「答错讲解」对用户是同一件事：**我不懂 → 问 → 得到解释**。
分开两处，想「我之前问过什么」要翻两个地方。现在合成一处，用来源页签区分。
备选名（用户还没最终拍板）：「我的疑问」「问答库」。

## 七、验证工具与抓 B 站字幕的方法（这一轮摸出来的）

### 7.1 B 站字幕抓取（下次要读视频内容可以直接用）

未登录时字幕接口返回 `subtitle.subtitles: []` —— 实测直连、wbi 签名、
移动端 UA 三种都是空。**必须用已登录的浏览器。**

但 Edge 拒绝「默认数据目录 + 调试端口」（日志里：
`DevTools remote debugging requires a non-default data directory`），
而复制 Cookies 到别的目录也解不开（Edge 127+ 用 App-Bound Encryption，
日志 `Unable to decrypt key`）。

**走通的路**：让用户把整个 `%LOCALAPPDATA%\Microsoft\Edge\User Data`
当 `--user-data-dir` 用，开调试端口，然后在页面上下文里调
`x/player/wbi/v2` 拿 `subtitle_url`，再用 curl 下载那个 URL
（请求头带 `Referer: https://www.bilibili.com/video/<BVID>/`）。
字幕 JSON 的 `body[]` 每项有 `from`（秒）与 `content`。

### 7.2 桌面版更新的标准动作（与前几份一致，这里只记变化）

这一轮做了四次打包，流程稳定：
确认程序未运行 → 备份 exe + app.asar + default_app.asar 到 `.tmp/desktop-backup-<时间>/`
→ `TMPDIR/TEMP/TMP=E:/openleaner/.tmp/esbuild-tmp npm run electron:pack`
→ **先 `rm -rf release/win-unpacked/openleaner-data`**（每次都会重新生成 52M）
→ 三件套同批替换 → md5 全匹配 → CDP 验证。

**没有一次重新生成安装包**（用户的规矩：只有他让生成时才生成）。

## 九、给下一个接手的人

- **这一轮最贵的三条教训**（都在第五节）：
  闭包依赖漏字段、层外 CSS 规则、位置相反的两个面板用相反的 token。
  它们的共同点是 **断言全绿，界面是错的**。
  所以：**改 CSS / 改 useCallback 都要截图 + 读真实数据复核。**
- **「做了没接上」这一轮又犯了三次**：讲解的坑（缓存没有预读，重启就没了）、
  错误提示（`ApiError.hint` 一直存在但界面只读 `message`）、
  进阶出题（做完发现它只是「帮变式出题预先勾好维度」，被用户否掉并已完整移除）。
