# OpenLeaner · 功能清单（2026-11-06 深夜修订）

> 这份清单的目的是**一眼看清边界**：什么真能用、什么只是占位、什么是假的。
> 与 **`docs/交接文档-2026-11-06-深夜.md`** 配套读（它是最新的接手点）。
> 夜间版 `docs/交接文档-2026-11-06-夜间.md` 仍有效，但**第十节的 OCR 方向已被用户推翻**，以深夜版第四节为准。
> 本版增量：资料页新增「删除资料」；现有 OCR 实证判定不可用、下一轮改本地部署四引擎。
>
> 判定标准（严格）：
> - **✅ 真能用** = 走完了「界面操作 → 数据落库 → 再读出来」的闭环，且有验证脚本或实测记录。
> - **⚠️ 部分** = 入口存在且能用，但只覆盖了一部分场景，界面上要如实标注。
> - **🚧 占位** = 点进去有明确说明页，不假装能用。
> - **❌ 没做** = 代码里没有，界面上也没有入口。

## 二、逐页明细

### 1. 学习库（`today`）✅

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 今日概览 | ✅ | 到期数 / 可学数 / 已做数 / 今日正确率 / 平均掌握度，**全部来自同一时刻快照** |
| 主行动卡 | ✅ | 有到期 → 「开始复习」；无到期有新生 → 「学新内容」；都空 → 「已完成」（disabled，文案如实） |
| 欢迎引导（空库时） | ✅ | 三步：接入模型 → 添加资料 → 用资料出题；已连接时显示模型名，未连接时显示「还没接入模型 —— 去「设置」里添加一个就能开始出题」 |
| 三步引导里的按钮 | ✅ | 「添加资料」跳资料页、「去出题」跳出题页、底部一行说明 |

**已知问题**：「开始复习」与「学新内容」走的是同一个 `navigate('review')`，行为完全一样 —— 后者语义未实现。

### 2. 资料（`sources`）✅

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 文件导入（标签一） | ✅ | PDF / docx / pptx / md / txt / png / jpg / jpeg / webp / gif / bmp；支持**拖放**与多选 |
| 粘贴文本（标签二） | ✅ | 标题可改，空标题默认「粘贴的文本」 |
| 音频 / 录音（标签三） | 🚧 | 明确文案「音频转写还在做。现在需要的话，可以先用别的工具转成文字，再粘贴到「粘贴文本」里导入 —— 效果一样。」**没有上传控件** |
| 资料列表 | ✅ | 标题 + 类型 + 页数 + 段数；按 `createdAt` 倒序 |
| **删除资料**（深夜新增） | ✅ | 每行一个「删除」次要按钮 → `ConfirmDialog` 二次确认（标题点名资料、明说不能撤销）→ `SourceService.remove()` → 列表与侧栏计数同步。**级联删** `sourceSegments` / `sourceFiles` / `sourceAnnotations` / `sources`；**留孤儿** `knowledgePoints` / `generationRuns` / `decks` / `questions` / `reviewRecords` / `reviewLogs`（确认框里如实写明）。`scripts/verify-v2-delete-source.cjs` **28/28**（截图 + 查 IndexedDB 双验证） |
| 点资料行 | ✅ | **进入「整理知识点」页**（不是阅读原文 —— 阅读器还没做） |
| 侧栏资料数 | ✅ | 来自 `sourceService.list()` 真实数量（本轮修掉了写死 0 的谎言；删除后也会刷新） |
| 格式说明折叠 | ⚠️ | **有，但内容是错的**：标题写「PDF 解析 / 扫描件、公式多或大文件」，正文却说「JSON 题组存为草稿；字幕和录音在「音频 / 录音」里确认用量后导入」—— 前者是未做的功能，后者是根本不存在的流程（`SourcesPage.tsx:285-294`）。**该整段重写。** |

### 3. 整理知识点（`organize`）✅ 本轮新增

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 选资料 | ✅ | 下拉列出全部资料 |
| 选后端 | ✅ | 第一个永远是「示例后端（离线，不联网）」；真后端只列 `direct-api` 且 `hasCredential && status==='ready'` 的，不可用的会给出**具体原因** |
| 页码范围（可选） | ✅ | 两头都填或都留空；只填一头、非正整数都会给准确错误 |
| 估算 | ✅ | 显示「本次将处理 N 段（整份） 预计用量：约 X tokens」；算不出来显示「无法估算」，**不给假数字** |
| 开始整理 | ✅ | 真实调用 `knowledge.generate()`，逐条落库 |
| 实时进度 | ✅ | 百分比 + 已产出条数 + 未定位条数；分母是**估算总数**（不是段数，否则会算出 333%） |
| 停止 | ✅ | 本地 AbortController；停止后提示「停止前已产出的条目已经保存在下面的列表里」 |
| 结果列表 | ✅ | 每条显示：认知层级徽章 + 「可点回原文 · 第 N 页」或「没找到原文位置」+ 概念表述 + 原文引用 |
| 重跑提示 | ✅ | 同一后端上次有结果时警告「再整理一次会替换掉它们（换一个后端则两份并存）」 |
| 用量记账 | ✅ | 真后端会写 `usageRecords`（kind `organize`），mock 不写 |

**注意**：结果里的「可点回原文 · 第 N 页」**只是一个徽章，点了不会跳转**（阅读器没做）。

### 4. 创建题组（`generate`）⚠️

| 方式 | 状态 | 说明 |
| --- | --- | --- |
| 用资料出题 | ✅ | 选资料 → 选题型（单选/多选/填空）→ 选数量 → 估算 tokens → 生成并逐题检查 → 落成 deck |
| 导入 JSON 题组 | 🚧 | 卡片显示为「即将可用」（`ready: false`），点了不进入表单 |
| 案例分析题 | 🚧 | 同上 |
| 在主会话里录题 | 🚧 | 同上 |
| 缺知识点时的引导 | ✅ | 「这份资料还没有可出题的知识点。先到「整理知识点」把它过一遍」+ 跳转按钮 |
| 错误提示 | ✅ | 同时显示 message 与**下一步建议**（hint），例如余额不足会提示去充值 |

**已知问题**：出题语言写死 `'zh'`（`AppSettings.questionLanguage` 没有消费者，所以设置页没做这个开关）。

### 5. 复习（`review`）✅

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 队列 | ✅ | `dueAt <= 今天` 的卡片，**上限 30 张** |
| 题型渲染 | ✅ | 单选（点击选项）、多选（可多选）、填空（input）、简答（textarea）、纯知识点（只读，按钮变「看完了」） |
| 判定 | ✅ | 单选严格、多选顺序无关、填空/简答**宽松匹配**（阈值 0.6） |
| 揭晓 | ✅ | 答对/答错 + 正确答案 + 解析（知识点卡显示原文引用） |
| 0–5 评分 | ✅ | 六档映射到四级 `again/hard/good/easy`；**每一档显示 `schedule()` 真实算出的间隔**，不是写死的数字 |
| 掌握度 | ✅ | 顶部胶囊实时更新 |
| 进度 | ✅ | 「第 N / M 张」+ 已完成数 |

**已知问题**：
- 队列上限 30，界面**不提示「还有更多」**。
- `essay` 类型的题会渲染出一个没有输入框的提交按钮（当前生成不出 essay，是潜在炸弹）。

### 6. 统计（`stats`）✅

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 连续学习天数 | ✅ | `streakDays()` |
| 12 周热力图 | ✅ | 五档色阶 |
| 掌握度分布 | ✅ | 五档：未学 / 薄弱 / 学习中 / 熟悉 / 已掌握，带条形与计数 |
| 只统计池子里的卡 | ✅ | 概览数字与分布都基于 `cardPool`（题目 + 知识点），避免「数字互相矛盾」 |

### 7. 设置（`settings`）✅ 本轮新增

三个分类（左侧导航 + 右侧单面板，≤760px 变横向药丸条）：

| 分类 | 能力 |
| --- | --- |
| **学习库** | 建库（已有库时不显示）、改名、库信息（创建时间/最后更新/结构版本 v10/库内记录 N 条 + 15 个分区明细）、外观说明（**明说只有深色一种，没有切换入口**）、当前语言只读展示 |
| **模型与出题** | 后端卡片列表（名称/默认/状态/agent 应用/模型/地址/预设名/凭据提示/两个能力徽章/就地测试结果）；添加、编辑、删除（二次确认）、设为默认；**测试连接真的发一次 HTTP 请求**并就地显示 `✓ 连接正常 · model · N ms` 或 `✗ 错误 + hint`；服务商预设（8 个）、接口地址、模型名（带 datalist 建议）、API Key（password 型、永不回填）、能力复选框 |
| **备份与恢复** | 导出（显示将导出 N 条记录 + 明细 + 文件名 `X-YYYYMMDD.openleaner.json` + **明说不含 API Key 与资料原始文件**）；恢复（选择文件 → 预览文件名/大小/内容摘要 → 二次确认 → 整库替换 → 提示重新加载） |

**关键诚实设计**：
- 状态徽章只说「有凭据/没凭据」，**绝不把「填了 Key」说成「连接正常」**。
- 测试连接失败时 hint 一定显示（不是只给一句错误）。
- 恢复是**唯一会覆盖数据的操作**，所以必须预览 + 二次确认，且危险按钮不占第一顺位。
- 空库时**恢复入口仍然存在**（否则最需要它的场景被关掉了）。

### 8. 功能导览（`guide`）🚧

底部固定区入口，点进去是占位页。用户已说明「其他按钮项目后期我们会补上功能」，所以**保留入口**，不算假开关。

## 四、数据模型现状

| 表 | 写入者 | 读取者 |
| --- | --- | --- |
| `meta` | `library.create/rename` | 设置页、顶栏 |
| `settings` | `library.saveSettings` | 设置页（只读展示） |
| `sources` | 资料页导入 | 资料页、整理页、出题页 |
| `sourceSegments` | 解析器、OCR | 整理页、定位器 |
| `sourceFiles` | 导入时存原始字节 | 阅读器（未做）、OCR |
| `knowledgePoints` | 整理页 | 整理页、出题页、复习 |
| `generationRuns` | 整理页 | 整理页（显示上次结果） |
| `decks` | 出题页 | 出题页 |
| `questions` | 出题页 | 复习、出题页 |
| `reviewRecords` | 复习页 | 复习、统计、学习库 |
| `reviewLogs` | 复习页 | 统计（热力图、连续天数） |
| `answerRecords` | **v2 界面无写入者**（core 的 `DeckService.submitAnswer()` 有实现，但没人调） | `DeckService.getWrongQuestions()/getHistory()/getStats()`（同样没人调） |
| `backends` | 设置页 | 设置页、整理页、出题页 |
| `secrets` | 设置页 | 设置页、整理页、出题页（**只在调用时读**） |
| `usageRecords` | 整理页、出题页（仅真后端） | 设置页（未展示）/ 无界面 |
| `sourceAnnotations` | **无** | **无** |
| `slideDecks` / `slideImages` | **无** | **无** |

**三个空白表**是下一步的关键约束：

- **做错题页其实不用从零写**：`src/core/questions/service.ts:648` 的 `getWrongQuestions({deckId?, keyword?, onlyUnmastered?})` 已经实现了完整语义（「错题 = 最近一次作答是错的」，返回 `{question, lastRecord, wrongCount}[]` 并按 wrongCount 降序），`getHistory(questionId)` 与 `getStats(deckId)` 也都在。**但前提是有 `answerRecords` 数据**，而 v2 复习页走的是 `review-service.review()`（只写 `reviewRecords` + `reviewLogs`），**从不调 `DeckService.submitAnswer()`** → `answerRecords` 永远是空的。
  → **这是做错题页前必须先拍板的第一件事**：要么让复习页在判定对错时同时调 `submitAnswer()`（数据双写，语义最正），要么让错题页改用 `reviewLogs` 的 `grade`（`again`/`hard` 视为答错，但知识点卡没有对错概念，会混进来）。**两条路的数据模型不同，必须问用户。**

- `sourceAnnotations` 与 `slideDecks`/`slideImages` 的**写入实现都在 core 里**（`grep` 分别 4 处 / 2 处），只是 v2 界面没有任何入口。做批注/PPT 时是「接界面」，不是「从零」。**注意：`slideImages` 进了备份，`sourceFiles` 刻意不进**（见 `src/core/storage/types.ts:40-44` 的注释：50 页教材 PDF 二三十 MB，备份会被撑大十几倍；恢复后 `fileStored` 变 `false`，界面要如实关闭图文页）。

## 五、「假的」清单（必须记住，别再重复）

已经被**主动移除**的假开关（历史，别再加回来）：

1. 资料页的「联网检索」勾选框 —— 没实现。
2. 设置里的 `agent-app` 接入类型下拉项 —— 只对已有 agent-app 配置显示。
3. 本地 OCR「死标签」—— 引擎在但没入口，所以界面不摆标签。
4. 侧栏 EN 语言按钮 —— EN 从未实现。
5. 欢迎页「载入示例并开始导览」—— 实际不载入任何示例。
