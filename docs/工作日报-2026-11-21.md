## 十、这一天的教训

1. **「操作成功」不等于「做对了」。**
   脚本报成功、文件字节变了、界面显示「产出 144 条」—— 三样都成立，
   但用的是假后端。危险操作要**显式确认关键参数**，别信任界面默认值。

2. **危险选项不该是默认值。**
   「示例后端（离线）」被设成整理页默认项，等于把每个用户都当成在演示。

3. **换实现时要连着「怎么被看见」一起换。**
   只换数据层忘了渲染层，界面上就只剩半截。

4. **断言写得够宽 = 没在验。**
   「徽标不压文字」在间隙 3px 时也成立，改成要求 ≥8px 才有意义（反向验证过）。

5. **`check:css-vars` 通过 ≠ CSS 生效。**
   它只查变量有没有定义，**不查文件有没有被 import**。
   横板渲染成小方块那次就是这个原因。

6. **默认值有重量，界面有惯性，而用户会看截图。**
   今天两个错都是你看截图发现的，不是断言发现的。
