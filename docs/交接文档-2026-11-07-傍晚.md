### 1. 阅读器（`7650e7e` + `b9731fa`）

**这是本轮最基础的修复。** 之前知识点上写着「可点回原文 · 第 N 页」，但**点不动**——
`anchors` 里存着 `{sourceId, page, charStart, charEnd}`，全库却没有任何一处拿它定位正文。
等于对用户撒谎，比不写这个徽章更糟。

`src/v2/ui/ReaderPage.tsx`：
- 只认**页内偏移**（相对 `SourceSegment.text`），不用全文偏移
- 定位三级降级，且如实告诉用户是哪一级：`anchor`（偏移直接命中）/ `quote`（靠引文搜回来）/ `none`（只找到页码）
- 找不到就明说，仍显示那一页正文，**不硬套假位置**
- 高亮用 `<mark>`，不改变文本（复制出来还是原文）
- **「看原图」开关**：用 `renderSourcePage`（pdfjs → canvas → PNG）按页渲染
  PDF 原图，可与文字对照 —— 用户「对照检查 OCR 有没有错」就靠这个

### 2. 扫描件 OCR：本机 MinerU（`60fa137` + `2a7047e`）

**用户拍板**：用 MinerU，去掉 OCRmyPDF（因为 OCRmyPDF 的 `--ocr-engine`
只接受 `tesseract`，用户已否决 tesseract，选它等于没换引擎）。

```
src/core/mineru/
  materials 相关不在这一层
  convert.ts      needsConversion()：什么情况该走转换
  markdown.ts     mineru parse 的 Markdown → 按页正文（纯函数）
  write-back.ts   转成 segments 写回 sourceSegments
electron/mineru.cjs   探测 + 校验 + spawn + 进度解析（纯 Node，可不开窗口验）
electron/main.cjs     新增 IPC + 原文件路径登记（sourceId → 磁盘路径）
src/v2/ui/ConvertPanel.tsx   整理页里的转换入口
```

**三条铁律**：

1. **页码严格 1:1**。`page_idx` 从 0 开始要 +1；空页保留占位，**绝不跳过**——
   跳过会让后面所有页错位一格，用户拿「第 12 页」对原书第 12 页会发现对不上，
   而这种错在界面上完全看不出来。
2. **表格/公式块不进纯文本**。MinerU 给的是 HTML/LaTeX，塞进
   `sourceSegments.text` 会让全文搜索和字符锚点一起失效。
3. **Markdown 形式保留**。用户要求「MinerU 转换后的 pdf 也要是 Markdown 形式」，
   所以正文里的 `##` 保留，阅读器渲染成 `<h1>`-`<h4>`。

**进度是这轮的重点难点**（用户明确要求）：
`mineru parse --wait` 在结束前**什么都不打印**（StudyHub 文档原话）。
真正的 tqdm 在服务那边 —— `mineru server status --json` 的
`parse_server_stderr_logs` 字段（实测 1.7 秒返回，含最近 10 行）。
所以定时（4 秒）只读地问服务，抽出最后一个 tqdm 进度：

## 五、⚠️ 硬约束（违反会立刻出问题）

### 1. MinerU 的几个坑（全部实测过）

| 坑 | 现象 | 正确处理 |
|---|---|---|
| 用 `mineru-kit` | 撞模型锁报 `[WinError 5] 拒绝访问`，看起来像 PDF 坏了 | 用 `mineru parse`（走本地常驻服务） |
| 传 `MINERU_HOME` | 报 `invalid_doclib_token` | **有意不传**，让服务自己管 |
| 服务未启用 | `Local parse-server is disabled` | `mineru config set parse_server.local.mode managed` |
| 输出目录用系统 temp | `EPERM: operation not permitted, mkdir` | 用 `userData/mineru-jobs` |
| `--pages` 不写 `all` | 只转前 10 页，用户以为转完了 | 显式 `--pages all` |
| 忘记 `--wait` | 命令立刻返回，读输出时还是空的 | 必须 `--wait <秒>` |

本机 MinerU 位置：`E:\StudyHub\MinerU\venv\Scripts\mineru.exe`（4.1.7）。
home 在 `C:\Users\ASUS\.mineru`（服务自己用这个，别手动指）。

### 2. 数据模型不能乱动的地方

- **`sourceSegments.text` 是纯文本**（Markdown 允许，HTML 表格不允许）
- **anchor 的 `charStart/charEnd` 是页内偏移**，相对 `SourceSegment.text`
- **出题的 anchors 必须从素材继承**，绝不让模型给位置
- **docx 按章节切，PDF 按页切**，两者的 `page` 语义不同（见 `model.ts` 注释）

### 3. CSS 层级陷阱

`src/styles/base.css` 有个**无层级**的 `button{color:inherit}`。
CSS 级联是「层级先于特异性」，所以**在 `@layer` 里写多少特异性都赢不了它**。
改任何原生控件颜色，先把规则写在 `@layer` 外面。项目里踩过三次。

### 4. 设计系统六条

暖黑 `#161412` + 米色 `#ece4d6` + 单一朱砂 `#c93d22`（**只给主操作与进度**）。
(1) 选中态用中性色不用朱砂；(2) 纸卡三细节（顶部 2px 朱砂线 + 32px 横格 + 圆角 16px）；
(3) 字重只有 300/400/550/650；(4) 一屏一个填充主按钮；
(5) ≤560px 侧栏变抽屉；(6) 色值不要随意改。
