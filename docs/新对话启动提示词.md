## 几条必须遵守的

1. **改界面必须用 CDP 截图肉眼复核**。上一轮有 **8 个 bug 是测试全绿、看截图/查库才发现的**：判定面板文字看不见、错题页被压成竖条、「正确答案」标签竖排、下拉框数量显示两遍、禁用按钮像能点、勾选框的 ✓ 污染文本、两句矛盾提示同时出现、右侧白边。

   可用脚本：`node scripts/shot-custom-app.cjs --app .tmp/apprun --data .tmp/apprun/openleaner-data --out .verify-shots/x.png --port 9600 --click 设置`

2. **改数据流必须查 IndexedDB** 确认真写进/真删掉。

   可用脚本：`node scripts/probe-electron-idb.cjs --data "release/win-unpacked/openleaner-data"`

3. **不做假开关**：不做的功能就明说，不摆点了没反应的按钮。上一轮因此把三个「缺外部条件」的页从侧栏摘掉了。

4. **遇到需要拍板的岔路停下来问我**，不要自己决定。

5. **改 `GeneratePage.tsx` 要小心**，那是 CRLF/LF 混用的文件（546 CRLF / 19 bareLF），按行号批量替换会错位。

   用 `scripts/_patch.py` 改，它按文件实际行尾展开；改完核对行尾计数。**优先抽独立组件**。

6. **新增存储分区必须改三处**：`types.ts`（STORES + BACKUP_STORES）、`DB_VERSION` + `LIBRARY_SCHEMA_VERSION`、`migrations.ts` 加一条规则。

   上一轮漏了 `DB_VERSION`，导致新分区在老用户的库里建不出来 —— **类型检查抓不到**，因为那是数字不是类型。

7. **做功能前先查两处，别重复造轮子**：

   - 先看 StudyHub 怎么做的：<https://github.com/EricWang1358/dsh-web-studyhub>
     （raw.githubusercontent 在这网络下不通，用 `api.github.com/repos/.../contents/<path>` 取 base64）
   - 再上网搜有没有更好的方案
   - 查过的结论写进注释并标明来源

   注意：**StudyHub 是 DSH 插件，我们是独立软件**。它依赖「主会话」「后台任务侧栏」这类概念，照搬前先想清楚在我们这儿成不成立。

8. **不显示「建议时长」**。我明确否决过这个功能（「这个不好估计」）。内部用来归一化可以，摆到界面上就是误导 —— 有测试锁死。
