>
> 判定标准（严格）：
> - **✅ 真能用** = 走完「界面操作 → 数据落库 → 再读出来」闭环，有验证脚本或实测记录。
> - **⚠️ 部分** = 入口能用，但只覆盖部分场景，界面上如实标注。
> - **🚧 占位** = 点进去有明确说明，不假装能用。
> - **❌ 没做** = 代码里没有，界面上也没有入口。

## 三、OCR（MinerU）专项

| 项 | 值 |
| --- | --- |
| 引擎 | MinerU 4.1.7（本机 `E:\StudyHub\MinerU`） |
| 调用方式 | `mineru parse --tier <tier> --pages all --wait --json -o x.md` |
| 走什么 | **本地常驻服务**（不是 `mineru-kit` 一次性 CLI） |
| 输出 | Markdown，自带 `<!-- page N of M -->` 分页标记 |
| 进度来源 | `mineru server status --json` 的 `parse_server_stderr_logs`（tqdm 实时输出） |
| 实测速度 | 单页约 15 秒（standard / RTX 4060）；50 页约 61 秒 |
| 档位 | `basic`（ONNX 小模型，819MB）/ `standard`（+VLM，约 2GB） |
| 页码对应 | **严格 1:1**，空页保留占位，绝不跳过 |

**已知限制**：
- 628 页大书的完整耗时**未端到端实测**（按单页速度推算约 26 分钟）
- 首次运行可能要下载模型（约 1.2GB），期间界面显示「下载模型」进度
- 表格与公式**不进纯文本正文**（会破坏搜索与字符锚点），只保留文字
