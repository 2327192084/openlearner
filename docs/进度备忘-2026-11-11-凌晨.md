## 本机踩过的坑（都已写进注释/脚本，别重复踩）

1. **electron-builder 的 nsis 目标在这台机器上坏了**
   - 日志特征：`Install data: 0 / 8 bytes`，产物 189KB 全是卸载器
   - 根因：两步编译的第二步（运行中间产物释放卸载器）进程退出码 null
   - **解法**：手写 `build/installer.nsi`，直接调 makensis（已提交）

2. **构建需要的三个环境变量**（缺一个就联网下载或失败）
   ```bash
   ELECTRON_BUILDER_7ZIP_PATH=<项目>/node_modules/7zip-bin/win/x64/7za.exe
   ELECTRON_BUILDER_NSIS_DIR=%LOCALAPPDATA%\electron-builder\Cache\nsis-3.0.4.1
   ELECTRON_BUILDER_NSIS_RESOURCES_DIR=%LOCALAPPDATA%\electron-builder\Cache\nsis\nsis-resources-3.4.1
   ```
   `7zip-bin` 是 `npm install --no-save 7zip-bin` 装的。

3. **electronDist 指向本地**：`package.json` 里 `electronDist: node_modules/electron/dist`
   否则 builder 会去 GitHub 下 Electron 运行时（超时）。

4. **makensis 必须带 `-INPUTCHARSET UTF8`**，否则中文注释导致
   `Bad text encoding: installer.nsi:1`。

5. **打包 zip 要在目录内部执行**，否则压缩包内路径会带 `.tmp/portable/` 前缀。
